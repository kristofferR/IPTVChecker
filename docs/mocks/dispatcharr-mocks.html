2 · Sync to Dispatcharr

Shared behavior for all three variants:

  • Remove checkbox pre-checked for Dead, unchecked for everything else.
  • Auto-fix order: Alive by height desc (ties keep original order), then Untested, then Geoblocked/DRM/Placeholder in original order. Dead removed.
  • A channel whose every stream would be removed is skipped, never sent as an empty list.
  • The table shows one row per channel×stream, named Channel [n/count] Provider, exactly as the API source synthesizes it.

2A · Apply flow

Apply first re-fetches every affected channel's streams and compares against the loaded order. Nothing is written until drift is resolved. Stats push once, then one ordered write per channel, then optional hard deletes. A failure never stops the batch.
