Dispatcharr: findings on stream rows

In the channel-first table, a stream row shows only its status dot, account and stream name. Findings such as a mislabel or low FPS show up only in the side panel or the status filter. Frozen video and low bitrate appear as icons in the Bitrate column, which usually sits off-screen while the side panel is open. These mocks place each stream's findings on its own row.

Already decided: the label check reads the stream name (x-dispatcharr-stream-name), not the channel name. A stream named "US: DEMO NEWS 4K" that probes as 720p is therefore mislabeled, whatever the Dispatcharr channel is called. That fix ships with whichever option you pick.

B Icons beside the status dot

Stream rows leave the Status column empty apart from the dot, since the channel's health bar fills that column on the channel row. B places finding icons there. A tooltip shows the details. A dead stream shows its reason as short red text.

C Mark the measured values

C flags each finding on the value it describes: the resolution turns amber with the claimed label beside it, the FPS turns amber, and the Bitrate column keeps today's icons. The name column gets a small amber dot so the stream still stands out when those columns are scrolled away.

Smaller decisions

  • Channel health bar: keep it status-only and add each stream's findings to its tooltip line ("2. Provider A: Alive, 720p, not 4K"). Adding a bar color for "alive with issues" would make a fifth tone next to geoblocked, placeholder and provider down.
  • Unlabeled 4K: today a stream that is 4K but not named as such counts as mislabeled. I suggest showing it as a neutral blue "4K" chip that doesn't count toward Mislabeled, since it is good news.
  • Fix order: out of scope here. Ranking mislabeled streams lower can come later if you want it.
