What changes

Direction<html dir> from the launch locale. Physical Tailwind classes (about 95: ml-, pr-, left-, right-) become logical (ms-, pe-, start-, end-).
User dataChannel names, groups and programme titles render with dir="auto", so mixed playlists read correctly in every UI language. URLs, paths and codecs stay left to right.
IconsMirror icons that imply direction: history, external link, rescan arrow, chevrons, the health ring fill. Media controls (play, pause) and the sort arrow do not mirror.
DigitsIntl formats Arabic with ٠١٢٣ by default. Most Arabic streaming apps use 0123 for technical values. Toggle above to compare. Persian uses ۰۱۲۳.
GuideDecided: the EPG timeline mirrors too. Now sits next to the channel names on the right; later programmes extend leftward.
NativemacOS mirrors menus and moves window controls for RTL apps. Linux and Windows menus follow the OS language, so an Arabic UI on an English OS keeps left-to-right menus.
FontsSystem fonts cover Arabic on macOS and Windows. Linux needs Noto Sans Arabic; worth listing as an AUR dependency.
