First-start language prompt

Shown once, on the first start of the localized version, when the OS language is one of the 12. The app stays in English until the user answers. Each control speaks the language of whoever is likely to press it: the switch in the OS language, Keep English and the list in English.

Behavior

SwitchSaves the language and restarts. At first start nothing is loaded yet, so the restart is instant.
Keep EnglishSaves English; never asks again.
Other languagePicking any entry saves it and restarts.
Dismiss (A)Treated as Keep English.
Unsupported OS languageNo prompt. English, and Settings lists all languages.
Settings"System" leaves the list: the language is always an explicit choice after this.
