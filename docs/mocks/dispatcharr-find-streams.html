Find replacement streams (#249)

Full macOS app window, dark appearance, 1440x900, in the channel-first table picked earlier (V1). Green numbers mark what is new. All names and hosts are synthetic.

For a channel with dead or weak streams, search every provider stream Dispatcharr knows, scan the likely ones, and link the best. Shared across variants:

  • Entry points: Find streams on a channel row, always shown on all-dead channels and on hover for the rest. Variant B adds Find streams (n) to the filter row whenever channels have every stream dead; it opens on the first one and steps through them.
  • Search starts from the channel name and EPG ID. Candidates with the channel's EPG ID come first, then name similarity with quality tags and country prefixes ignored. Streams already linked are left out.
  • Scan uses the normal scanner and its per-account limits; a busy account shows as such, not as dead.
  • Link writes the full order with the usual drift check and Undo. Fix order can place new streams by the ranking in Settings.
  • Was linked marks streams unlinked from this channel this session, so a removal can be reversed from here.

AInline candidates under the expanded channel

Candidates line up in the table's own columns right under the dead streams, no new surface; the search bar and many rows push the rest of the table far down, and bulk work across channels has no home.
